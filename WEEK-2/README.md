Requirements

Install Node.js before running the JavaScript files.

Check if Node.js is installed:

node --version

Download Node.js from:

Node.js Official Website

How to Run

Open terminal in this folder and run:

node file-name.js

Example:

node shoppingCart.js

For folder-based projects:

cd Shopping
node app.js
