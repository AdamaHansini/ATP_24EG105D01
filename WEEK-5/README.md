Requirements
For HTML and CSS Projects

No installation is required.
You can directly open the HTML files in a browser.

For React Projects
Install Node.js and project dependencies before running the applications.

Check Node.js version:
node --version

Download Node.js from:
Node.js Official Website

How to Run HTML Projects
Open any HTML file in the browser.

Example:

PROJECT-1/index.html
PROJECT-2/index.html
PROJECT-3/index.html
tables.html

You can also use Visual Studio Code with Live Server.

Download VS Code from:
Visual Studio Code Official Website

How to Run React Projects
Run React App 1:
cd REACT-APP-1
npm install
npm run dev

Run React App 2:
cd REACT-APP-2
npm install
npm run dev
