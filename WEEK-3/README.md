WEEK-3 Backend Practice

This folder contains the backend practice work I completed during Week-3 while learning Node.js, Express.js, MongoDB, and JWT authentication.

In this practice, I learned how to create a backend server, connect it with MongoDB, create APIs, and protect routes using JWT tokens.
I also practiced testing APIs and organizing backend files properly.

Files Included
File Name                           	Purpose
server.js	                 Main server setup using Express
ProductAPI.js                   	Product API routes
ProductModel.js	          Product schema and model using Mongoose
auth.js                     	Authentication-related practice
verifyToken.js          	Middleware for verifying JWT tokens
req.http	                 Sample API requests for testing
package.json                	Dependencies and scripts
.env	                          Environment variables

Features I Practiced
Creating an Express server
Connecting MongoDB using Mongoose
Creating REST APIs
Adding, reading, updating, and deleting products
Using JWT authentication
Protecting routes with middleware
Testing APIs using HTTP requests
Using .env for environment variables
Requirements

Install Node.js and MongoDB before running the project.

Check Node.js version:
node --version

Install dependencies:
npm install

Download Node.js from:
Node.js Official Website

How to Run
Start the server using:

npm start
The application runs from the server.js file.

API Testing
The req.http file contains sample API requests for testing the endpoints.

I used REST Client / Postman to test:

GET requests
POST requests
PUT requests
DELETE requests
