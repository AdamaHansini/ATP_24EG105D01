# Employee Management Frontend

React app for employee management.

## Features

- View employees
- Add employees
- Edit employees
- Delete employees

## Tech

- React
- Vite
- Axios

## Install

cd FrontEnd
npm install

## Run

npm run dev
Visit http://localhost:5173

## Build

npm run build

## API

Backend: http://localhost:3000

## Structure

- components/ - UI
- contexts/ - State
- store/ - Stores
